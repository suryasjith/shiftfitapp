4. In-Depth Root Cause Breakdown & Codebreaking Findings

1. VISUAL INSTRUCTION SYSTEM CORRUPTION & MISMATCHED MEDIA Critical Integrity Flaw
Root Cause: src/data/exerciseDatabase.ts assigned random Unsplash stock photography to exercises, with 18 of 21 exercises recycling identical stock photos. For instance, a user viewing Wide-Grip Lat Pulldown is shown a man doing floor pushups. A user viewing Cable Face Pull is shown the exact same photo as Incline Dumbbell Press. Furthermore, WorkoutTab.tsx claimed visual movements were "Looping Visuals", but rendered static JPEGs with a pulsing amber dot.
// src/data/exerciseDatabase.ts (Before Fix) 'incline_db_press': { visualGifUrl: 'https://images.unsplash.com/photo-1581009146145-b5ef050c2e1e...' } 'face_pull': { visualGifUrl: 'https://images.unsplash.com/photo-1581009146145-b5ef050c2e1e...' } // DUPLICATE! 'lat_pulldown': { visualGifUrl: 'https://images.unsplash.com/photo-1598971639058-fab3c3109a00...' } // PUSHUP IMAGE!
2. BEGINNER EXERCISE ADAPTATION ENGINE FAILURE Critical Safety Flaw
Root Cause: BEGINNER_EXERCISE_ADAPTATIONS in src/services/weightSuggestionEngine.ts declared replacements for high-axial compound movements (e.g. replacing hack_squat with seated_leg_press, and incline_db_press with machine_chest_press). However, these replacement IDs were never registered in EXERCISE_DATABASE. To prevent a fatal runtime crash, recompPrograms.ts was silently patched with resolvedId = exerciseId;, leaving absolute beginners on dangerous free-weight compound lifts while giving them a misleading note!
// src/data/recompPrograms.ts:21 if (isBeginner && BEGINNER_EXERCISE_ADAPTATIONS[exerciseId]) { resolvedId = exerciseId; // SILENTLY ABANDONED ADAPTATION! }
3. ONBOARDING PROFILE MACRO DESYNCHRONIZATION Critical Logic Flaw
Root Cause: In OnboardingOverlay.tsx:45, when a user completes onboarding, handleFinish updates gender, heightCm, currentWeightKg, and desiredWeightKg, but completely omits recalculating shiftDayMacros and offDayMacros. As a result, a 41kg female beginner receives the hardcoded 80kg male profile targets (~185g protein, 2400 kcal) instead of biologically tailored targets (~85g protein, 1450 kcal).
4. DARK MODE "ZEBRA CONTRAST" & ILLEGIBILITY COLLAPSE High UI/UX Flaw
Root Cause: 1. Header.tsx and Navbar.tsx hardcode light offwhite backgrounds (bg-[#FBF9F5] / bg-stone-100) with no dark mode variants, resulting in a bright offwhite header and navigation bar sandwiching pitch-black cards. 2. OnboardingOverlay.tsx uses a pure white container (bg-white). When html.dark enforces color: #FFFFFF !important, all modal text renders as invisible white-on-white text. 3. WorkoutTab.tsx embeds bg-[#FBF9F5] on the Form Guide card inside the dark exercise card. 4. Primary button styling converts to a blinding solid pure white slab with black text, while secondary buttons render as unstyled dark holes.

5. Comprehensive Technical Remediation Plan

Phase 1: True Exercise Visuals Database & Verified Instructional GIFs

  • Integrate verified, open-source exercise execution images from yuhonas/free-exercise-db where each exercise has verified start position (0.jpg) and peak contraction position (1.jpg).
  • Implement an animated dual-frame transition or verified instructional animation so users see the actual biomechanical path (e.g., Lat Pulldown pulling to clavicle, Lateral Raise leading with elbows in the scapular plane).
  • Register the missing beginner adaptation movements in EXERCISE_DATABASE:
    • seated_leg_press: 45° Seated Leg Press Machine
    • machine_chest_press: Seated Selectorized Chest Press
    • db_romanian_deadlift_light: Dumbbell Romanian Deadlift (Form Focus)

Phase 2: Dark Mode UI/UX Architecture (Pending User Approval)

  • Replace jarring pitch black (#000000) with a balanced, deep slate architectural foundation (#0B0F19 or Deep Zinc #090D16) to eliminate optical halation and eye fatigue.
  • Apply consistent dark backgrounds to Header.tsx, Navbar.tsx, OnboardingOverlay.tsx, and InstallBanner.tsx to eliminate the zebra clash.
  • Refactor primary tactile buttons from blinding white slabs to warm, high-contrast athletic accents (e.g. Electric Terracotta #EA580C or Refined Warm Amber #F59E0B) with crisp white text and tactile press-down states.
